# flock Implementation Plan

> **For agentic workers:** executed natively (superpowers:executing-plans) in the authoring session; the user
> authorised implementation without further review gates. Code is written test-first during execution
> rather than duplicated here; each task lists its files, interfaces and the tests that must pass.

**Goal:** Build `flock`, a Go binary that adds an agent-aware sidebar, labels, per-session notes,
notifications and a polybar feed on top of a stock i3 + tmux setup.

**Architecture:** One daemon owns all state (i3 IPC + tmux polling + agent hook events over a Unix
socket) and broadcasts snapshots; the sidebar, bar and notes editor are thin clients. Short-lived
subcommands (called from i3 bindings and agent hooks) talk to the daemon over the same socket.

**Tech Stack:** Go 1.26; go.i3wm.org/i3/v4; charmbracelet bubbletea + lipgloss; godbus/dbus/v5;
jezek/xgb; BurntSushi/toml. tmux ≥ 3.2, i3 ≥ 4.22.

**Spec:** docs/superpowers/specs/2026-10-11-flock-design.md

## Global Constraints

- No cgo; single static binary; module `github.com/murrayb52/flock`.
- i3 ≥ 4.22, tmux ≥ 3.2; private tmux server name `flock`; sidebar WM class `flock-sidebar`.
- Socket `$XDG_RUNTIME_DIR/flock/flock.sock`; data `$XDG_DATA_HOME/flock/` (default `~/.local/share/flock`);
  config `$XDG_CONFIG_HOME/flock/config.toml` (optional).
- `flock hook …` must never print to stdout, never exit non-zero, and finish in < 300 ms when the daemon is absent.
- Status logos: input `!` red #E53935, done `✓` green #52b788, working spinner amber #f0b429, idle `○` grey. No pulsing.
- British English in user-facing text.

## Review Focus

1. Daemon not running when a hook fires or a binding is pressed → hook silent/exit 0; binding exits quietly with a hint on stderr.
2. Labels/notes containing quotes, `#`, `%` or unicode → stored and displayed verbatim (tmux `#` escaped as `##`).
3. A pane whose agent crashed (no SessionEnd) → agent cleared once the pane's foreground command is a shell again.
4. Windows/workspaces closing while the sidebar is open, empty workspaces, nested split containers → no panic, sensible grouping.
5. Two agents resumed from the same session id in different panes, or resume in another terminal → notes follow the session id.

### Task 1: Module skeleton, shared model, CLI dispatch
**Files:** `go.mod`, `cmd/flock/main.go`, `internal/model/model.go`, `internal/config/config.go` (+ `_test.go`)
**Produces:** `model.{Note, Agent, Term, Window, Group, Workspace, Snapshot, Status}`; `config.Load() Config`
with `Terminal`, `SidebarWidth`, `RailWidth`, `Paths{Socket, Data}`; `main` dispatching subcommands.
**Tests:** config defaults + TOML override + XDG path resolution.

### Task 2: Agent state machine
**Files:** `internal/agents/agents.go` (+ test)
**Interfaces:** `type Event{Agent, Name, Pane, SessionID, Source, Prompt, Detail, Question}`;
`(*Table).Apply(ev, now, isFocused func(pane) bool) []Change`; `Change{Pane, Notify: none|input|done, Cleared bool}`;
`(*Table).Seen(pane)`, `(*Table).ClearPane(pane)`, `(*Table).Get(pane) *model.Agent`.
**Tests:** start→idle; prompt→working (prompt stored); permission→input (detail kept, Notify input);
post-tool after input→working; stop→idle unseen + Notify done unless focused; focus clears unseen;
end clears; Pi question at settle→input; resume keeps session id.

### Task 3: Hook payload adapters
**Files:** `internal/hook/claude.go`, `internal/hook/pi.go` (+ tests with payloads captured in the spike)
**Interfaces:** `FromClaude(event string, payload []byte, pane string) (agents.Event, bool)`;
Pi extension sends `agents.Event` JSON directly (documented shape).
**Tests:** each Claude event maps correctly; PermissionRequest detail = Bash command or tool name;
Notification idle_prompt ignored; malformed JSON → ok=false.

### Task 4: Session store (labels + notes)
**Files:** `internal/sessions/store.go` (+ test)
**Interfaces:** `Store{Dir}`; `Load(kind, id) Record`; `Save(kind, id, Record) error` (atomic rename);
`Record{Label string; Notes []model.Note; Updated time.Time}`.
**Tests:** round trip; missing file → empty; unsafe ids sanitised; unicode/quotes preserved.

### Task 5: i3 tree → workspaces/groups, slot planning
**Files:** `internal/i3tree/tree.go`, `internal/i3tree/slot.go` (+ tests with JSON fixtures)
**Interfaces:** `Build(root *i3.Node, terms map[string]*model.Term) []model.Workspace`
(matches `[flock:<id>]` title marker, classes → app keys, group labels, slots, focused/visible);
`PlanSlot(root *i3.Node, con i3.NodeID, slot int) []string` (i3 commands).
**Tests:** split h with stack + stack; single stack; nested split; empty workspace; scratchpad and
sidebar windows excluded; slot plan up/down/left/right, clamp, no-op.

### Task 6: Naming, icons, logos (shared UI vocabulary)
**Files:** `internal/ui/ui.go` (+ test)
**Interfaces:** `Name(w model.Window) (string, bool)`; `Tile(w) Tile{Glyph, BG, FG}`; `StatusOf(a *model.Agent) model.Status`;
`WorkspaceStatus(ws) model.Status`; `Logo(s, frame) (glyph, colour)`; `StateText(a) string`; `Elapsed(d) string`.
**Tests:** label beats prompt beats `zsh — dir`; known classes; status priority input>done>working>idle.

### Task 7: tmux integration
**Files:** `internal/tmux/tmux.go`, `internal/tmux/conf.go` (+ tests; integration test against a real private server)
**Interfaces:** `Client{Socket string}`; `ListPanes() ([]Pane, error)` (session, pane id, cwd, command, @flock_label);
`Set(session string, opts map[string]string) error` (batched); `Popup(session, cmd string, h int) error`;
`ClosePopup(session)`; `Prompt(session, prompt, initial, template string) error`; `Config(bin string) string`;
`Header(...)` formatting with `#` escaping.
**Tests:** config contains required options; header escaping; integration: new session, set option, list panes.

### Task 8: Daemon core (socket, protocol, broadcast, persistence wiring)
**Files:** `internal/protocol/protocol.go`, `internal/daemon/{daemon.go,server.go,snapshot.go}` (+ tests)
**Interfaces:** request `{op: event|subscribe|cmd|get-notes|set-notes|set-label, …}`; `daemon.New(cfg, deps)`;
deps interfaces `I3`, `Tmux`, `Notifier`, `Urgency` so tests use fakes.
**Tests:** event → snapshot broadcast to subscriber; set-notes persists to store; set-label on agent pane
goes to session record, on plain pane to tmux option; daemon-absent client error path.

### Task 9: Notifications, urgency, focus actions
**Files:** `internal/notify/notify.go`, `internal/x11/urgency.go`, daemon wiring
**Behaviour:** input → critical notification "<name> needs your input" + urgency; done → normal; one
notification per pane (replaces); default action focuses the window; focusing clears both.
**Tests:** daemon-level with fakes (calls recorded); manual check in Xephyr.

### Task 10: Commands (slot, next, jump, label, notes, sidebar placement/toggle)
**Files:** `internal/daemon/commands.go`, `internal/daemon/sidebar.go` (+ tests with fakes)
**Tests:** next ordering (input oldest first, then unseen done); label/notes act on focused flock term only;
sidebar placement commands for expanded/condensed and gap = actual width.

### Task 11: Notes editor TUI
**Files:** `internal/notesui/{editor.go,app.go}` (+ editor test)
**Tests:** key model exactly as spec (Tab/Shift+Tab/↑/↓, Space tick, typing edits, Enter/Esc finish, Del, new row, Esc close drops empties).

### Task 12: Sidebar TUI
**Files:** `internal/sidebar/{view.go,app.go}` (+ view tests on fixed snapshots)
**Tests:** expanded rows (slots, ◉, notes [x/N], italic auto names), rail mode below 20 columns, empty workspace, mouse row hit-testing.

### Task 13: Bar feed
**Files:** `internal/bar/bar.go` (+ test)
**Tests:** focused/urgent/plain workspace formatting, logo choice, `N:Name` → `N Name`, click actions.

### Task 14: Installers and examples
**Files:** `internal/install/{claude.go,pi.go}`, `integrations/pi/flock.ts`, `examples/i3.conf`, `examples/polybar.ini`
**Tests:** hook merge is idempotent, keeps user hooks, removes only flock's on `uninstall`.

### Task 15: End-to-end in Xephyr, fake agent, GIFs, README, publish
**Files:** `demo/fake-agent.sh`, `demo/record.sh`, `README.md`, `docs/*.gif`
**Steps:** run nested i3 with examples, drive with xdotool + fake agent, verify behaviour, record GIFs,
write README (credit herdr: local-only, inspired by https://herdr.dev/), create public GitHub repo and push.
Then a `flock` branch in `~/projects/linux-setup` wiring the user's i3/polybar (not applied live).
